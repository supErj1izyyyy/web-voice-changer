📐 Dasar Teori & Persamaan Matematis DSP

Penjelasan ilmiah untuk Tugas Akhir Mata Kuliah Pemrosesan Sinyal Digital.

1. Konvolusi Waktu Diskrit (Discrete Convolution)

Sinyal output \( y[n] \) dari sistem LTI (Linear Time-Invariant) merupakan hasil operasi konvolusi antara sinyal input \( x[n] \) dengan respon impuls sistem \( h[n] \):

y[n] = x[n] * h[n] = ∑ [k = -∞ sampai ∞] x[k] · h[n - k]

Pada web ini, konvolusi digunakan untuk menghitung efek reverberasi dan pemfilteran respon impuls audio.

2. Sistem Kausal (Causality & Difference Equation)

Suatu sistem dikatakan kausal jika keluarannya pada sembarang waktu \( n \) hanya bergantung pada nilai masukan saat ini dan masa lalu, bukan masa depan:

h[n] = 0, untuk n < 0

Implementasi filter IIR (Infinite Impulse Response) dan Biquad Equalizer diturunkan dari persamaan beda kausal:

y[n] = b₀·x[n] + b₁·x[n-1] + b₂·x[n-2] - a₁·y[n-1] - a₂·y[n-2]

Dan untuk efek Echo/Delay kausal dengan waktu tunda \( D \) sampel dan gain feedback \( \alpha \):

y[n] = x[n] + α · y[n - D]

3. Fast Fourier Transform (FFT & Analisis Spektrum)

Untuk memvisualisasikan spektrum sinyal suara masukan \( X[k] \) dan keluaran \( Y[k] \), dilakukan transformasi dari domain waktu ke domain frekuensi menggunakan algoritma Discrete Fourier Transform (DFT) cepat berukuran \( N = 1024 \) titik:

X[k] = ∑ [n = 0 sampai N-1] x[n] · e^(-j · 2π · k · n / N)

Besaran magnitudo spektrum (dalam satuan desibel/dB) yang digambar pada canvas:

|X[k]| = √( Re(X[k])² + Im(X[k])² ),   dB[k] = 20 · log₁₀(|X[k]|)

4. DSP Formant Shaping (Pemodelan Suara Vokal)

Saluran vokal manusia dimodelkan sebagai filter akustik dengan frekuensi resonansi alami (formants \( F_1, F_2, F_3 \)). Modifikasi pitch dan bobot penguatan pita formant tertentu memungkinkan transformasi timbre suara dari satu karakter ke karakter lainnya tanpa memerlukan inferensi neural network yang berat.
